# AE-2 M7 - Practicando CRUD con Django

Repositorio correspondiente a actividad de clase, con objetivo de aplicar conociemientos sobre CRUD en un proyecto Django.
Este proyecto se creó en un entorno local y consiste en un proyecto con su respectivos archivos, entre los cuales se encuentra _models.py_ que contiene el modelo __Socio__. Este último es el foco de esta actividad, ya que se trabajó con este modelo a nivel de Django y su verificación en PostgreSQL (pgAdmin).
Además, se incluye una carpeta llamada ___img proof___ que contiene el archivo visual del proceso y lo requerido por la actividad, probablemente se añadirán a este archivo. 
Se está contemplando si habrán futuros avances en este proyecto, pero por ahora este sería el resultado final..
